Talk to the Widget

Tonight you'll take a bare chip, load your own firmware onto it, and get it to talk back. By the end you'll have flashed a real microcontroller, opened a serial link to it, and tracked down the flags hidden inside.

What is this thing?

The board in front of you is an ESP32-C3. It's a full computer smaller than a stick of gum, and it's the same kind of chip you'll find inside smart plugs, doorbells, and cheap toys. Hardware cyber starts when you stop treating a device as a sealed box and start loading your own code onto it and reading what it says back.

Three words worth knowing tonight:

  • Firmware. The program that runs on the chip. You can overwrite it, and you will.
  • Serial. A plain-text conversation between your laptop and the board over the USB cable.
  • Buffer. A fixed-size slot for data, and where a lot of security bugs begin.
🚩 Flags look like this: TTU{ ... }

Part 1 · Flash your firmware

Flashing means writing a new program onto the chip. You're going to do it yourself.

Which terminal? Every command below works the same in Windows PowerShell and Git Bash. Just run each line on its own. The one thing that changes between them is how you put two commands on one line: cmd1 && cmd2 in Git Bash, or cmd1; if ($?) { cmd2 } in PowerShell, which doesn't accept &&. We write python -m esptool and python -m mpremote because they work right after pip install. If you type plain esptool and get "not recognized," that's just a PATH thing, and the python -m form gets around it.

  1. Plug the board into your laptop with the USB-C cable.
  2. Install the two tools (one time): 
    pip install esptool mpremote
  3. Find the board's port. On Windows, open Device Manager and look under Ports (COM & LPT) for a new COM#. On Mac or Linux it's a /dev/tty.* or /dev/ttyACM0. The commands below say COM5, so put in whatever yours is.
  4. Wipe the chip, then write MicroPython, the base system your firmware runs on: 
    python -m esptool --port COM5 erase-flash
python -m esptool --port COM5 write-flash -z 0x0 ESP32_GENERIC_C3-20260824-v1.29.0.bin
  5. Copy tonight's program onto it as main.py, the file the board runs at boot, then reboot: 
    python -m mpremote connect COM5 fs cp hcig_intro.py :main.py
python -m mpremote connect COM5 reset

The firmware image and hcig_intro.py are in the shared folder and on the USB stick we passed around.

Part 2 · Say something to it

Now open a serial terminal. It's just a window that shows the text the board sends and lets you type back.

  1. Connect at 115200 baud, 8N1. Any of these work: 
    python -m mpremote connect COM5 repl
# ...or open PuTTY / Tera Term / MobaXterm on COM5 at 115200
  2. You should see a big SmartWidget 3000 banner and a widget> prompt. If not, press Enter, or unplug and replug the board.
  3. Type anything. Your letters show up on screen because the board is echoing them back. That round trip is your code running on the chip and reacting to each key.
  4. Type help and press Enter to see what it knows.
Nothing shows up when I type?

Check that you connected to the board's COM port at 115200. Press Enter once, or unplug and replug the board to bring the banner back. Still nothing? Grab a facilitator.

Part 3 · Find the flags

The walkthrough stops here. There are four flags in the widget, and each one prints on your screen when you reach it. They look like TTU{ ... }.

A few places to look:

  • Run help and work through the commands it lists.
  • The board takes input from more than the keyboard. Check the hardware, not just the terminal.
  • Try giving it more input than it seems to expect.
  • One command wants a password. This unit never changed its default, and the password is sitting in the firmware you flashed, wrapped in a common text encoding you can undo in seconds.

If you get stuck, ask a facilitator. Bring the flags you find so we can record them.

Rules of engagement. Everything tonight runs on hardware we handed you and asked you to break. Never point any of this at a device, network, or account you don't own or have clear permission to test.
